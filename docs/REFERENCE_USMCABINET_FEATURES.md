# USMCabinet 成品软件功能区学习记录

记录时间：2026-06-03

参考程序：
`E:\尝试搭建模块\别人的成品\USMCabinet(2)\USMCabinet\USMCabinet.exe`

`E:\尝试搭建模块\output\reference-usmcabinet`

## 1. 程序类型与内部模块

这是一个 Unity 打包的 Windows 程序。核心程序集位于：

`USMCabinet_Data\Managed\Assembly-CSharp.dll`

反射看到的主要模块：

- `StructUiManager`：左侧结构 UI，负责尺寸按钮、结构元素按钮、滚轮按钮。
- `CabinetUIManager`：宽度、高度、深度输入框，撤销、重置、截图、设置按钮。
- `Cabinet`：单个柜体模块，保存面、梁、立柱、顶点的显示状态。
- `CabinetBuilder`：创建、重建柜体，更新选中柜体尺寸。
- `BaseStructElement`：更高层的模块关系逻辑，支持向上、左右、前方扩展。
- `CabinetPresetManager`：批量隐藏/恢复结构面。
- `CabinetColorManager`：颜色网格，支持全部或单体上色。
- `WheelManager`：底部脚垫/滚轮切换。
- `CabinetDimensionVisualizer`：整体和分项尺寸标注。
- `SettingsManager`：设置面板，全屏、分辨率、退出。

## 2. 总体交互规则

核心规则：先点击 3D 模块，左侧输入和结构选择才会绑定到当前模块。

选中模块后：

- 模块边缘出现黄色选中框。
- 模块周围出现黑色圆形 `+` 扩展按钮。
- 左侧“结构选择”列表展开，可勾选/取消单个结构件。
- 左侧宽度、高度、深度输入框变成当前模块可编辑尺寸。

如果没有先点模块，输入框可能只显示值或保留上次状态，不能可靠驱动当前模块更新。

## 3. 尺寸区

左侧尺寸分为三组：

- 宽度 mm：预设 `750 / 500 / 395 / 350 / 250`，最右侧输入框支持自定义。
- 高度 mm：预设 `500 / 395 / 350 / 250 / 175 / 100`，最右侧输入框支持自定义。
- 深度 mm：预设 `500 / 395 / 350 / 250`，最右侧输入框支持自定义。

已验证自定义输入：

- 先点模块，再把宽度改为 `620`，顶部内部宽度标注变成 `620 mm`，整体宽度变成 `643 mm`。
- 先点模块，再把高度改为 `430`，内部高度标注变成 `430 mm`，整体高度变成 `470 mm`。
- 先点模块，再把深度改为 `455`，内部深度标注变成 `455 mm`，整体深度变成 `478 mm`。

尺寸外框规则：

- 整体宽度 = 内部宽度 + `23 mm`
- 整体深度 = 内部深度 + `23 mm`
- 脚垫状态下整体高度 = 内部高度 + `40 mm`

## 4. 结构元素区

“结构元素”下面有 4 个缩略图按钮，属于批量结构预设。

观察到的效果：

- 第 1 个：恢复完整箱体。
- 第 2 个：去正面面板。
- 第 3 个：去四面面板。
- 第 4 个：隐藏所有面板，保留框架、梁、立柱和节点。

这些按钮不是普通格子类型选择，而是批量隐藏/恢复面板类结构。

## 5. 滚轮选择区

“滚轮选择”有 3 个缩略图：

- 第 1 个：脚垫/普通支撑。
- 第 2 个：一种滚轮样式。
- 第 3 个：另一种滚轮样式。

程序内部 `RollerOption` 包含：

- `imageName`
- `modelName`
- `describe`
- `height`

说明滚轮不仅改变模型，也可能影响离地高度和整体高度。

## 6. 结构选择区

选中模块后，“结构选择”会变成可滚动清单。它的粒度很细，不只是门板开关。

已看到的项目包括：

- 右面
- 顶面
- 底面
- 顶前横梁
- 顶后横梁
- 底前横梁
- 底后横梁
- 前左立柱
- 前右立柱
- 后左立柱
- 后右立柱
- 顶左纵梁
- 顶右纵梁
- 底左纵梁
- 底右纵梁
- 左前上顶点
- 右前上顶点
- 左后上顶点
- 右后上顶点
- 左前下顶点
- 右前下顶点
- 左后下顶点
- 右后下顶点

内部 `Cabinet` 类也对应三组可见性数组：

- `FaceVisibility`
- `PillarVisibility`
- `VertexVisibility`

并且有三组手动覆盖数组：

- `FaceManualOverride`
- `PillarManualOverride`
- `VertexManualOverride`

这说明软件会区分自动相邻隐藏和用户手动隐藏，后续复刻时不能只用一个布尔值。

## 7. 加号扩展

选中模块后，模块上方、左侧、右侧和正面附近会出现 `+`。

程序内部 `BaseStructElement` 支持：

- `addTop()`
- `addRight()`
- `addLeft()`
- `addFront()`

同时有相邻关系字段：

- `frontStructElement`
- `backStructElement`
- `leftStructElement`
- `rightStructElement`
- `topStructElement`
- `bottomStructElement`

这说明它不是简单调整列数/层数，而是以单个模块为节点，通过相邻关系扩展柜体。

尺寸联动逻辑也在 `BaseStructElement` 中：

- 改宽度会影响同列/相邻结构位置。
- 改高度会影响同层或向上结构。
- 改深度会影响前后连接结构。

## 9. 底部工具按钮

左下底部有 4 个工具按钮：

- 设置：打开设置面板。
- 截图：导出/保存当前视图截图。
- 撤销：恢复上一步操作。
- 重置：清空或恢复默认项目。

反射对应字段：

- `openSettingsBtn`
- `screenshotBtn`
- `undoBtn`
- `resetBtn`

## 10. 与当前项目的差距

当前本地项目 `usm-local-builder` 已经有：

- 3D 预览
- 宽/高/深预设
- 多列多层配置
- 颜色
- BOM/估价
- 截图、导入导出

与成品软件相比，主要缺口是：

- 自定义宽/高/深输入应绑定“当前选中模块”，而不是只用固定选项。
- 结构选择应升级为面、梁、立柱、顶点的独立开关。
- 结构开关要区分自动隐藏和手动隐藏。
- 结构元素缩略图应做成批量结构预设：完整、去正面、去前后、去四面/全框架。
- 柜体扩展应从“增减列/层”升级为基于选中模块的上、左、右、前方向 `+` 扩展。
- 颜色应支持“全部/单体”作用范围。
- 滚轮/脚垫应支持至少 3 种样式，并影响整体高度。
- 尺寸标注应同时显示内部尺寸和整体尺寸，整体尺寸按外框余量计算。

## 11. 建议实现顺序

1. 增加模块选中态：所有尺寸输入、结构开关、颜色单体模式都绑定当前模块。
2. 把尺寸选项从固定枚举改成“预设按钮 + 自定义输入”。
3. 引入外框尺寸规则：宽/深 +23mm，高度按脚垫/滚轮补偿。
4. 为每个模块增加 `faces / pillars / vertices` 可见性与手动覆盖状态。
5. 增加结构选择清单，实现单个面、梁、立柱、顶点开关。
6. 增加 4 个结构元素批量预设。
7. 增加上、左、右、前方向扩展按钮和相邻关系。
8. 增加颜色“全部/单体”模式。
9. 增加 3 种脚垫/滚轮模型和高度补偿。
