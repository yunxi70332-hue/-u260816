## 一、问题背景

在「结构」大类编辑时，选中格子会显示黄色高亮框（`#ffe100`）。业务场景：截图一个款式发给客户时，黄条无法取消，导出的图片也带黄框，观感不佳。

## 二、设计思路

成熟的同类设计器均遵循同一模式：编辑时显示高亮选中便于操作，但所有导出功能在截图前自动清空选中、导出后恢复现场：

```
captureUiStateForReport()   // 1. 保存当前编辑状态
clearAllSelections()        // 2. 清空所有选中
renderModel() → 截图        // 3. 干净渲染并抓图
restoreUiStateAfterReport() // 4. finally 恢复原状态
```

这样导出物（效果图、四视图 PDF、图册素材等）永远是干净的，用户从不需要手动取消选中。本次更新把这套「导出即干净、编辑态可释放」的思路应用到 C 端设计器。

## 三、更新内容

### 1. 点击 3D 视口空白处 → 释放编辑状态（核心交互）

- **改动前**：`selectCell(null)` 收到空选中时直接 return，且 `activeSelection` 的推导会把空值强行解析回最近的格子，导致点空白永远取消不掉黄框。
- **改动后**：
  - 「结构」大类下，点击视口背景空白或地面空白 → 取消选中：黄框消失、悬浮「撤销/删除」工具条隐藏、左下角显示「未选中」、左侧格子编辑区置灰；全局尺寸编辑（全柜默认深度、深度段数等）照常可用。
  - 点击柜体任意格子 → 立即恢复选中，进入正常编辑。
  - 框架 / 配件 / 颜色三个大类的选中行为保持不变（仅结构大类响应空白点击释放）。

### 2. 新增「隐藏选中框（截图用）」眼睛按钮

- 顶栏和底部工具栏各加一个眼睛图标按钮（图标随状态切换 Eye / EyeOff）。
- 点击或按 **Esc** 键可随时隐藏 / 恢复选中框，隐藏时悬浮工具条一并隐藏，方便直接拍屏幕发给客户。
- 点击任意格子自动退出隐藏模式，回到编辑状态。
- 只读订单视图也提供该按钮。

### 3. 「导出图片」自动输出干净图

- 点击「导出图片」（顶栏）或「载图」（底部工具栏）时，截图瞬间自动隐藏选中框，截完自动恢复编辑状态——无论当前是否选中，导出的 PNG 都不带黄框。
- C 端导出埋点事件（`portal/*/events` 的 `exported` 里程碑）保持原有行为不变。

## 四、代码改动明细（src/App.tsx）

| 位置 | 改动 |
| --- | --- |
| 图标导入 | 新增 `EyeOff` |
| 组件状态 | 新增 `const [presenting, setPresenting] = useState(false)` |

| `exportImage` | 导出前隐藏选中框、双 rAF + 90ms 后抓图、finally 恢复；新增 `togglePresenting` |
| BuilderScene 接线 | `selection={presenting ? null : activeSelection}` |
| 悬浮工具条 | 增加 `!presenting` 条件 |
| 工具栏 | 顶栏（只读 / 常规）与底部工具栏各新增眼睛按钮 |

## 六、使用建议

- **给客户拍屏**：结构大类点一下空白（或按 Esc）→ 柜子干净后再截屏。
- **拿图片文件**：直接点「导出图片」，无需任何手动操作，导出即干净。
- 三种方式（空白点击 / 眼睛按钮 / 自动导出）可按习惯自由组合。
