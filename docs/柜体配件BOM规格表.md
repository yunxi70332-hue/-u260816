# 柜体配件 BOM 规格表

> 依据：配置器拆单逻辑 `src/model.ts` 的 `buildBom()`（`src/model.ts:2059`）及配件目录 `src/accessoryCatalog.ts:59`、官方散件匹配 `src/official-bulk-sku-catalog.ts:369`。
> 整理日期：2026-09-07。
>
> 口径说明：本文只覆盖**柜体配件**（前脸门类、抽屉、内置配件、底部支撑、软包板）及其触发五金；框架部分（球节点 / 钢管 / 膨胀螺丝）与纯结构板件（金属扣板 / 外板 / 内板）只列配件触发的关联项。

---

## 1. 拆单总流程（配件相关）

`buildBom()` 按以下顺序输出，同名 + 同规格 + 同颜色 + 同表面处理的行自动合并数量（`addItem()`，`src/model.ts:3959`）：

1. 框架件（球节点、钢管、膨胀螺丝、底部支撑）；
2. 工厂板件（`addFactoryPanelBom`）——配件所在格会强制生成金属安装面（见 §7）；
3. 逐格扫描配件：
   - 下翻门格 / 带下翻门前脸 → `addDropDoorFactoryBom()` 拆成 8 行工厂明细；
   - 开放格 → 前脸配件行 + 内置配件行；
   - 其余复合类型（上翻门、玻璃门、软包、托盘等）→ 目录复合行 + 前脸/内置明细；
4. 台面（跨格桌面 / 桥接台面）。

配件格的规格基准：`宽 x 高 x 深 mm`，其中宽 = 列宽、高 = 行高、深 = 该深度段格深（`getCellDepth`）。

## 7. 配件触发的关联结构件

配件会改变格子板件输出（`needsFactoryMountingFace`，`src/model.ts:2337`；`occupiesPhysicalPanel`，`src/model.ts:2302`）：

| 规则 | 输出影响 |
|------|---------|
| 格子带门/抽屉/托盘/搁板/托盘类配件 | 开放格背/侧面补金属安装面（金属扣板或外板，价格 `180 + 面积×0.00018`） |
| 前脸配件或一字拉手抽屉所在面 | 该面**不再输出**结构板（被配件本体占据） |
| 相邻格子共享安装面 | 输出「扣板（四排孔）」`深 x 高 mm` + **大角码 2 个**；洞洞板安装面则输出洞洞板 + 大角码 2 个 |
| 结构面材质为玻璃（玻璃模块格 / 面板改玻璃） | 玻璃板 `宽 x 高 mm`（`260 + 面积×0.00048`）+ **玻璃夹角 4 个** |
| 每根钢管 | 膨胀螺丝 2 颗（框架件，随配件柜体一并输出） |

## 8. 尺寸与颜色规则

### 8.1 名义尺寸 → 工厂尺寸映射

板件/门板按 `factoryPanelDimension`（−15 口径，`src/model.ts:2396`）显示工厂规格；钢管 −18（`factoryTubeLength`）；玻璃板 −20、玻璃门 −22（官方散件匹配口径）：

| 名义 (mm) | 板件工厂 (mm) | 钢管工厂 (mm) |
|-----------|--------------|--------------|
| 750 | 735 | 732 |
| 580 | 580 | 577 |
| 500 | 485 | 482 |
| 395 | 380 | 377 |
| 350 | 335 | 332 |
| 300 | 285 | 282 |
| 250 | 235 | 232 |
| 175 | 160 | 157 |
| 150 | 135 | — |
| 100 | 85 | 82 |

非表内名义尺寸：板件 = 名义−15，钢管 = 名义−18。

### 8.2 面宽与方向

- 前脸配件 / 一字拉手抽屉可四向安装（前/后/左/右）；左/右向安装时**面宽 = 格深**，面深 = 格宽；`faceSide = back` 的格子方向自动镜像。
- 规格串固定附「前向 / 后向 / 左向 / 右向」；玻璃门另附「左把手 / 右把手」。

### 8.3 颜色追踪

以下 BOM 名称输出时在规格尾追加「/ 颜色 类别」（如 `/ 黑色 A类`），同色才合并行（`COLOR_AWARE_BOM_NAMES`，`src/model.ts:225`）：

- 板件/门类：金属扣板、顶板、底板、外板、内板、扣板（四排孔）、前板、后板、左侧板、右侧板、门板、洞洞板；
- 前缀匹配：下翻门、上翻门、玻璃门组件；
- 精确匹配：抽屉盒组件；
- 配件：移动托盘、固定搁板、展示托盘、围边。

颜色分档：黑色/白色/奶咖色为 A 类；钢蓝色/橄榄绿为 B 类；其余（宝石蓝、鹅黄、橙、粉红、西子蓝、绿、红、黄、银、深灰、棕）为 C 类（`COLOR_OPTIONS`，`src/model.ts:375`）。
