## 一、问题现象

- 电脑浏览器（http://127.0.0.1:9011）：选中面板 → 左侧出现"当前零件"栏 → 点"删除当前零件"弹出确认 → 删除成功。
- iPad（Safari 访问 modun.usmax.xyz）：能选中面板、能弹出确认删除的弹窗，但**确认后删除不生效**，无任何反应。
- iPad 顶部同时有"价格计算失败"提示（按用户要求暂不处理）。

## 二、根因

删除确认使用浏览器原生 `window.confirm`（原 src/App.tsx:565）。iOS Safari 会静默拦截原生确认框：

- "添加到主屏幕"的独立窗口模式下完全不弹窗；
- 连续弹窗后系统会抑制后续弹窗；
- 被拦截时 `confirm` 直接返回 `false`，代码走了"取消"分支。

所以 iPad 上点了删除毫无反应；电脑浏览器不受影响。

3D 触屏选取本身没有问题（代码里已针对 `pointerType === "touch"` 放大命中半径）。

## 三、修复方案（已完成并验证）

### 3.1 自定义确认弹窗替换 window.confirm

- `src/App.tsx`：新增 `frameDeleteConfirm` 状态；删除时改为弹出自建 `alertdialog`（含完整级联删除提示文案：钢管/球节点/面板/底座数量与外尺寸不变说明）；点遮罩或"取消"关闭；"确认删除"才执行 `applyFramePartRemoval`。
- `src/styles.css`：新增 `.app-confirm-backdrop / .app-confirm-modal / .app-confirm-actions` 样式；按钮高 46px、`touch-action: manipulation`，对手指点击友好。

### 5.2 已修复的 3 类同类隐患

#### P1：3D 画布 touch-action 被改为 auto

- **现象**：canvas 上存在内联 `touch-action: auto`（来自 three-stdlib OrbitControls 的 `dispose()` 逻辑，node_modules/three-stdlib/controls/OrbitControls.js:309）。CSS 规则压不过内联样式。
- **后果**：iPad/手机上双指捏合会变成**缩放网页而不是缩放模型**；快速连点零件可能触发 iOS 双击缩放页面。
- **修复**：
  - `src/BuilderScene.tsx`（SceneReady useEffect）：场景每次就绪时强制 `gl.domElement.style.touchAction = "none"`；
  - `src/styles.css`：新增 `canvas { touch-action: none; }` 作为兜底。
- **验证**：实测内联与计算样式均为 `none`。

#### P2：文件下载同步 revokeObjectURL（共 8 处）

- **后果**：`a.click()` 后立刻 `URL.revokeObjectURL`，iOS Safari 的下载是异步启动的，同步 revoke 会中断下载——导出 JSON/BOM/PNG、ERP 价格表 CSV/Excel 模板等在移动端"时灵时不灵"。
- **修复**：全部改为 `window.setTimeout(() => URL.revokeObjectURL(url), 1000)`：
  - `src/App.tsx` downloadFile（JSON/BOM/配件清单导出）+ PNG 导出走 dataURL 无此问题；
  - `apps/erp/src/pages/price-list-detail.tsx`（2 处）；
  - `apps/erp/src/lib/price-import.ts`（1 处）；
  - `apps/erp/src/pages/inventory.tsx`（2 处）；
  - `apps/erp/src/pages/pricing.tsx` downloadText（1 处）；
  - `apps/erp/src/lib/inventory-import.ts`（setTimeout 0 → 1000）。
  - 参考：`sales-contract.ts` 原本就用 1000ms 延迟，是正确范式。

#### P2：localStorage 写入无异常保护（3 个文件 4 处）

- **后果**：iOS 私密浏览/存储配额满/锁定模式下 `setItem` 抛 QuotaExceededError；设计器那处在 useEffect 中未捕获，**会导致整页白屏崩溃**。
- **修复**：全部包 try/catch，存储不可用时仅跳过本地持久化：
  - `src/App.tsx`（配置自动保存 useEffect）；
  - `src/erp/DesignerErpPanel.tsx` persistActiveDesign；
  - `apps/erp/src/context/auth.tsx`（demo 登录 + 切换企业，2 处）。
