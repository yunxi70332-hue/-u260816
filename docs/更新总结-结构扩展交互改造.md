## 一、需求背景

USM 模块柜 3D 配置器中，原交互为：选中格子后点击周边"+"号，会**一次性增加整排/整列**已启用的格子。

参照官方配置器（partnershop.spine.usm.com）的使用习惯，改为两级操作：

1. **单击加一格**：点击任意方向的"+"号，每次只新增一格（新行/列中仅紧邻选中格的那格启用，其余为不可见占位）。
2. **全选新增一列**：悬停选中格**左/右/顶**任一"+"号时，对应方向外侧浮现"全选新增一列"胶囊按钮；点击后把当前格所在**整列**克隆为相邻新列，**门板、配件、颜色等全套配置随列复制**，源列中的空洞（禁用格）同样保留，新列整列黄色高亮。
   - 左侧悬停 → 新列插在源列**左侧**
   - 右侧/顶部悬停 → 新列插在源列**右侧**

## 二、实现内容

### 1. 数据模型（`src/model.ts`）

| 函数 | 改动 |
|------|------|
| `insertColumn` / `insertRow` / `insertDepthSegment` | 新增可选激活位参数 `active`：传入时新行/列仅激活指定格，其余插入 `{ kind: "metalBackModule", enabled: false }` 占位 |
| `insertFrontDepthSegment` | 支持激活位；"门板后移 + 背板壳"转换仅对激活格应用 |
| `expandCell` | 上/下/左/右/前五个边缘分支改为单格语义，选中态移动到新格 |
| `cloneColumn`（新增） | 整列克隆：新列复制源列**每格完整配置**（kind、门板前置配件、内部配件、颜色、结构覆盖，经 `cloneCell` 深拷贝），源列中的禁用格同样保留；列宽复制源列（同模块参数）；支持指定插入位置；守卫 `MAX_GRID_COUNT`（10 列上限） |

### 2. 3D 场景（`src/BuilderScene.tsx`）

- **胶囊按钮**：`ExpandHints` 在悬停左/右/顶"+"时渲染"全选新增一列"胶囊（canvas 贴图，黑底黄字黄边），带隐形碰撞盒，悬停变黄。
- **视口钳制**：胶囊位置每帧按当前相机投影计算，超出屏幕自动拉回可见区域——贴边场景（如单列柜左侧）也始终完整可见可点。
- **统一屏幕空间命中**：`getExpandActionAt` 把 5 个"+"提示与 3 个胶囊位置统一投影到屏幕，点击时取距离最近者：
  - 点胶囊附近（44px 内）→ 触发整列克隆（含 `side` 方向）
  - 点"+"附近（32px 内）→ 单格新增
  - 不再依赖 3D 射线是否恰好命中胶囊碰撞盒
- **宽限期**：胶囊失焦后保留 2 秒才卸载，鼠标从"+"移向胶囊途中经过空白区域不会中途消失。
- **整列高亮**：新增 `highlightColumn` 渲染，对高亮列的所有已启用格子逐个绘制 `SelectionFrame`。

### 3. 应用层（`src/App.tsx`）

- 新增 `highlightColumn` 状态与 `cloneSelectedColumn(side)`：
  - 走现有 `updateConfig` 通道（自动进撤销历史、C 端注册门槛照常生效）
  - 克隆后选中态移到新列对应格，并设置整列高亮
- `selectCell`（点击任意格子）、`undoLast`（撤销）时退出整列选中态
- `canCloneColumn = 列数 < 10` 控制胶囊显隐

- 新增 `scripts/verify-single-cell-clone.ts` 回归脚本（tsx 运行）

## 三、过程中定位并修复的问题

| 问题 | 根因 | 修复 |
|------|------|------|
| 悬停左侧"+"看不到胶囊 | 单列柜时左侧"+"贴近屏幕左缘，胶囊向外偏移后被渲染到**屏幕外** | 胶囊位置按相机视口钳制 |
| 点胶囊变成"加一格" | 胶囊点击依赖 3D 射线命中碰撞盒；鼠标移动途中胶囊消失或射线被挡时，点击退化命中"+"提示 | 统一屏幕空间就近命中判定（见上） |
| 鼠标移向胶囊途中胶囊消失 | 失焦即卸载 | 2 秒宽限期 |
| 开发时改代码不生效 / 行为时对时错 | **工作区路径含中文（`E:\票务回收\`）导致 Vite 文件监听不可靠**，模块转换缓存滞后，页面运行新旧混合代码 | 改代码后重启 `pnpm dev` 并强刷页面；生产构建（`vite build`）不受影响 |
