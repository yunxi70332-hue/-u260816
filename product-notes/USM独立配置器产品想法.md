# USM 独立配置器产品想法记录

## 1. 产品定位

目标是开发一个独立运行的模块化家具配置器，参考 USM 官方 Web Configurator 的核心体验，但不依赖 USM iframe、线上接口、官方资源或专有嵌入页面。

这个产品更像一个本地可控的设计与报价工具：用户可以在浏览器或 Windows 本地环境里完成柜体搭建、尺寸调整、颜色选择、结构预览、方案保存和导出。它服务于销售沟通、客户方案确认、工厂拆单前置整理和内部快速打样。

关键原则：

- 独立：不嵌入 USM 官方 iframe，不调用官方私有接口。
- 本地：核心搭建、预览、保存和导出能力可以离线运行。
- 可解释：尺寸、结构、BOM、报价逻辑尽量透明，便于后续接入真实工厂规则。
- 可扩展：先做可用的模块化搭建体验，再逐步增加真实 SKU、报价、拆单和方案管理。

## 2. 参考对象

参考 USM 官方 Web Configurator 的主要流程和信息架构，而不是复制其实现。

重点参考能力：

- 结构页：深度、高度、宽度预设与自定义输入。
- 安装件页：门、背板、侧板、搁板、抽屉、托盘、玻璃件等模块选择。
- 颜色页：多色板件选择，并支持全部或单体作用范围。
- 3D 预览：实时显示柜体结构、门板状态、框架、球节点、脚垫或脚轮。
- 尺寸标注：显示内部尺寸和外部尺寸，辅助客户确认比例。
-扩展交互：围绕选中模块向上、左右、前方扩展。
- 导出能力：截图、配置文件、BOM 或报价数据。

参考边界：

- 可以参考复制官方 UI 资源、图片、模型、接口和私有数据。
- 不承诺官方价格、官方 SKU 或官方结构合法性。
- 本产品输出是本地估算和方案表达，后续需要与工厂规则校准。

## 3. 当前项目现状

当前工作区已有一个 React + Three.js 本地原型，具备继续产品化的基础。

已具备的方向包括：

- 基于 Vite、React、Three.js 的 3D 预览。
- 柜体宽度、高度、深度配置。
- 多列、多层模块搭建。
- 板件颜色、钢管表面、脚垫和脚轮切换。
- 结构模式切换，例如完整柜体、隐藏正面、仅开放格、全框架。
- 单元格类型选择，例如开放格、背板、下翻门、玻璃门、抽屉、托盘、搁板等。
- 本地配置保存、JSON 导入导出、PNG 截图、BOM CSV 和估价雏形。

当前更像“可验证方向的原型”，下一步应把它梳理成稳定的产品体验：明确用户路径、模块数据模型、结构约束、导出格式和版本边界。

## 4. 核心体验目标

用户打开配置器后，应能不阅读说明就完成一套柜体方案。

核心路径：

1. 选择或创建一个基础柜体。
2. 点击 3D 里的某个模块，使其成为当前编辑对象。
3. 调整当前模块的宽度、高度、深度。
4. 为当前模块选择结构件，例如开放格、背板、门、抽屉、托盘或玻璃件。
5. 通过加号向上、向左、向右或向前扩展柜体。
6. 选择颜色，并决定应用到全部柜体还是单个模块。
7. 切换脚垫、低脚轮或高脚轮。
8. 查看内部尺寸、外部尺寸、估算价格和基础 BOM。
9. 导出图片、配置 JSON 和 BOM 表，用于沟通或后续报价。

体验要求：

- 3D 是主工作区，左侧或侧边栏是配置面板。
- 所有编辑动作都围绕“当前选中模块”展开。
- 选中状态要明确，例如黄色边框或高亮轮廓。
- 结构、颜色、尺寸修改后即时刷新 3D 结果。
- 导出内容要可读、可复用、可交给后续报价或拆单流程。

## 5. MVP 范围

MVP 目标是做成一个可用于内部演示和基础客户沟通的独立配置器。

必须包含：

- 3D 柜体搭建和 Orbit 视角控制。
- 选中模块、当前模块高亮和模块级编辑。
- 宽度、高度、深度预设按钮与自定义输入。
- 向上、向左、向右、向前扩展模块。
- 常用结构件：开放格、金属背板、无背板、下翻门、上翻门、侧开门、玻璃门、搁板、拉出搁板、抽屉盒、展示托盘、玻璃搁板。
- 颜色选择，并支持全部或单体作用范围。
- 底部支撑：脚垫、低脚轮、高脚轮，并影响外部高度。
- 尺寸标注：内部宽高深、外部宽高深。
- 截图导出。
- 配置 JSON 导入导出。
- 基础 BOM 与本地估价。
- 本地自动保存。

暂不纳入 MVP：

- 官方 USM SKU。
- 官方报价。
- 官方模型或贴图。
- 复杂结构合法性校验。
- 多用户协作。
- 云端账号体系。
- 在线订单支付。

## 6. 后续版本方向

### V1：产品化本地配置器

- 优化 UI 信息架构，让结构、安装件、颜色、BOM 更清晰。
- 增加结构件独立开关，例如面、梁、立柱、顶点的显隐控制。
- 增加撤销、重做、重置和方案复制。
- 固化导出 JSON 版本号，避免后续升级破坏旧方案。

### V2：报价和 BOM 增强

- 接入真实零件表、材料表和工厂报价规则。
- 区分展示报价、销售报价和工厂成本。
- 输出更接近工厂可用的 BOM。
- 增加报价备注、折扣、运输、安装等费用项。

### V3：方案管理

- 支持多个方案列表。
- 支持客户信息、项目名称、房间位置和备注。
- 支持方案复制、归档和版本对比。
- 支持导出 PDF 报价单或方案确认单。

### V4：桌面版和生产流程

- 打包 Windows 桌面版。
- 支持离线安装包。
- 接入工厂拆单格式。
- 增加木箱尺寸、包装体积、物流费用估算。
- 支持销售、设计、报价、生产之间的数据流转。

## 7. 产品开发边界

这个配置器应该明确标注为“独立本地配置工具”，避免用户误解为官方 USM 系统。

需要持续坚持的边界：

- 适当参考使用 USM 官方 iframe。
- 可以参考依赖 USM 官方线上接口。
- 可以抓取或内置官方受保护资源。
- 不把估价表达为官方报价。
- 不把本地 BOM 表达为官方 SKU 清单。
- 所有规则都应可被本地数据表替换和校准。

## 8. 后续可拆任务

优先级建议：

1. 整理当前数据模型，明确模块、尺寸、结构件、颜色、底部支撑和导出格式。
2. 把“选中模块”作为所有编辑动作的中心。
3. 完善结构件库和 3D 表现，让每个安装件都有稳定的本地模型。
4. 增加结构显隐细粒度控制，支持面、梁、立柱、顶点级别开关。
5. 梳理 BOM 与估价数据表，为真实报价规则预留接口。
6. 优化移动端和桌面端布局，保证销售演示时操作顺畅。
7. 增加 PDF 或图片方案导出，用于客户确认。
